# Ngebut JLPT

Single-file web app latihan JLPT N5–N3 (kosakata, partikel, bunpou, dokkai) + mode "Daftar salah".

## Akses Online (GitHub Pages)

Setelah GitHub Pages diaktifkan untuk repo ini, aplikasinya bisa diakses di:
https://dadikirawan.github.io/ngebut-jlpt/

Cara aktifkan:
1. Buka tab Settings repo
2. Pilih Pages
3. Source: Deploy from a branch
4. Branch: main / (root) lalu Save
5. Tunggu sebentar sampai status "Your site is live"

## Jalankan Lokal

Buka `index.html` di browser.
